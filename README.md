# رحلة لقمة — مختبر الجهاز الهضمي التفاعلي

موقع تعليمي عربي تفاعلي للفصل الرابع «الجهاز الهضمي» من كتاب الأحياء للصف الثالث المتوسط.

## التشغيل
افتح index.html مباشرة في متصفح حديث. لا يحتاج المشروع إلى تثبيت مكتبات JavaScript أو خادم.

## المحتوى
- رسم تشريحي مبسط قابل للنقر والتكبير مع بطاقة شرح لكل عضو.
- رحلة الغذاء ومراحل الهضم وتكوين الكيموس والكيلوس.
- الغدد الملحقة ووظائف الكبد والبنكرياس والغدد اللعابية.
- مكونات الغذاء والفيتامينات والأملاح والماء.
- الأمراض والوقاية بحسب الكتاب.
- خريطة ذهنية واختبار تفاعلي من 8 أسئلة.

## المصدر
كتاب الأحياء للصف الثالث المتوسط، الفصل الرابع «الجهاز الهضمي»، الصفحات المطبوعة 41–56. الرسوم مبسطة لأغراض التعليم وليست بديلاً عن الرسم المطلوب حفظه في الكتاب.
